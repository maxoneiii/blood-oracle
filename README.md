# Blood Oracle

An alternative character sheet for the **World of Darkness 5e** system (`wod5e`)
on **Foundry VTT V14**, ported from the standalone Blood Oracle sheet.

It registers itself alongside the system's own sheets. Nothing changes until you
pick it in an actor's Sheet Configuration, and the system stays the default.

## What it covers

**Vampires, ghouls, mortals and story characters**, each with its own palette,
showing only what that kind of character has: a mortal gets no Blood or
Disciplines, a ghoul no Hunger or Blood Potency.

**Eight tabs** — Biography, Statistics, Blood, Disciplines, Merits & flaws,
Inventory, Notes & XP, plus a pool constructor.

**Rolls** through the system's own API, so dice, chat cards, Dice So Nice and the
system's Willpower reroll all keep working. The pool constructor handles blood
surge, specialties, resonance, Blood Potency bonuses, impairment, weapon damage
and heavy-armour penalties. Powers roll from the sheet and pay their Rouse cost
afterwards — asking first where the book leaves a choice.

**Coteries, packs and cells** on a group sheet, over the system's own fields.

**A detective board** as an alternative Journal sheet: as many boards as the
table wants, cards private on creation, the Storyteller seeing everything.

**Token statuses** for Hunger and impairment, kept in step with the character.

**A padlock** that protects ratings from stray clicks, per user.

## The rules reference

The sheet can read a rules reference — clans, predator types, powers, rituals,
merits, flaws, Humanity and Blood Potency tables — which drives the catalogues,
the search, the prerequisite and amalgam checks, and the full-rules panels.

**It is not distributed with the module, and cannot be.** It is close to verbatim
book text. The reference is generated by its owner, from material they already
have, and lives in Foundry's `Data` directory on the server; every client fetches
it from there, so only the Storyteller's machine needs a copy.

Without it the sheet works, but every catalogue is empty and everything is
entered by hand. The module says so on load rather than looking broken.

See `RULES.md` for how to generate and install one.

## Installing

Foundry → Add-on Modules → Install Module → paste the manifest URL, or copy
`module.json`, `dist/`, `icons/` and `fonts/` into `Data/modules/blood-oracle/`
by hand.

Requires the `wod5e` system, 5.3 or newer, on Foundry V14.

## Building

```bash
npm install
npm run build
```

`RELEASING.md` covers publishing and updates.
